The assignment listed these as optional. I used all five, each for a reason.

  • Terraform: the whole environment is code I can review, rebuild, and destroy with one command, so nothing is left billing.
  • GitHub Actions: every push is tested, then deployed. If the new version fails its health check, it rolls back by itself.
  • Docker: what I test is exactly what runs in production.
  • HTTPS: a free certificate that renews itself. It should be the default.
  • Monitoring: a probe outside the server checks this site every five minutes and emails me if it fails twice.
