The first deploy failed before it built anything: AWS said GitHub was "not authorized" to use the deploy role, with no other detail.

  1. Was the role name wrong? No, it matched.
  2. Was GitHub's identity provider set up wrong in AWS? No, the address and audience matched.
  3. Was it the wrong branch? No, it was main.
  4. How does GitHub identify this repository? That was it. New repositories include numeric IDs, and my AWS policy expected the old format.

Fix: the exact value is now a required setting, read from GitHub's API. Prevention: it's in the runbook, with the one command that confirms it.
